# 本部とグループホームの同期（Firebase）

グループホームのPCと本部のPCで、同じデータを使うための設定です。データは**暗号化（AES-256-GCM）してから**
Firebase の Firestore に置きます。暗号の鍵は事業所のPCにしかないので、Google・Firebase からは中身が見えません。

## しくみ

| | グループホームのPC | 本部のPC |
|---|---|---|
| ふだん直せるもの | 入居者・日誌・支援記録・実績・入院帰省・勤務表・勤務の確定・研修・献立など | 請求・給与・経費・加算・処遇改善・設定・ログインする人・今日のやることの「済」 |
| 相手のもの | 見るだけ | 見るだけ |
| 本部操作のあいだ | **すべて見るだけ**（画面に「本部操作中」） | すべて直せる |

- それぞれ自分の分を1分ごとに送り、相手の分を受け取ります（GHMS が動いているあいだ）
- 本部で入力（日誌・実績など）を直すときは「設定 → 本部とグループホームの同期」で**本部操作をオン**。
  グループホームのPCが最新のデータを送ってから、本部で直せるようになります。終わったら**オフ**にします
- グループホームのPCが止まっているときは「強制」でオンにできます（グループホームのPCで、まだ送れていなかった入力は反映されず、そのPCのバックアップ「同期の前」に残ります）
- パスワード・PINの変更は、どちらのPCで変えても両方に届きます
- 操作の記録は、両方のPCの分がそろいます
- 同期を使っているあいだは「バックアップから元にもどす」は使えません（同期をやめてから）

## Firebase の準備（給与計算ソフトの Firebase プロジェクトを使う）

1. Firebase コンソール → **Authentication** → ログイン方法で「メール / パスワード」を有効にする
2. 同期用のログイン（例 `ghms-sync@自社のドメイン` とパスワード）は、GHMS の「① このPCで始める」で
   「新しく作る」にチェックすると、GHMS が作ります（Firebase の画面で Authentication → ユーザー → ユーザーを追加 で作ってもよい）。
   職員のログインとは別にし、パスワードは12文字以上の、ほかで使っていないものに
3. **Firestore Database** の「ルール」に、次を**今のルールに足す**（給与計算ソフトのルールは消さない）。
   メールは2で作ったものに変える

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // （ここに給与計算ソフトの今のルール）

    // GHMS の同期：同期用のログインだけが読み書きできる
    match /ghms_sync/{site}/{rest=**} {
      allow read, write: if request.auth != null
                         && request.auth.token.email == "ghms-sync@example.com";
    }
  }
}
```

4. プロジェクトの設定 → 全般 で **ウェブ API キー** と **プロジェクト ID** を控える

料金：Firestore の無料の範囲（Spark プラン：1日 書きこみ2万回・読みこみ5万回・保存1GB）に収まる見込みです
（1分ごとの確認で、1台あたり1日 数千回）。

## 設定のしかた（本部を先に）

1. **本部のPC**に GHMS を入れ、はじめての設定をする。入居者・職員・住居と、**グループホームの職員のログイン**（設定 → ログインする人）も本部で作る
2. 本部のPCで「設定 → 本部とグループホームの同期」→「① このPCで始める」：役「本部」、事業所のID（例 `office1`）、Firebase の4項目を入れて「つないで始める」
3. 「接続ファイルを保存」で `ghms-connect.txt` を USBメモリに保存
4. **グループホームのPC**に GHMS を入れ、はじめての設定をすませる（ここで作ったログインは、本部のログインに置きかわります）
5. グループホームのPCで「設定 → 本部とグループホームの同期」→「② 接続ファイルで参加する」でファイルを選ぶ
6. 1〜2分で本部のデータがすべて届きます。本部で作ったログインで入り直してください
7. 接続ファイルは USBメモリから消す（同期用のパスワードと暗号の鍵が入っています）

グループホームが参加するまでは、本部のPCで入居者・日誌なども直せます。参加したあとは、入力はグループホーム、請求・給与・設定・ログインする人は本部です。

## 気をつけること

- 鍵・同期用のパスワードはデータのフォルダの `sync.json` にあります（バックアップには入りません）。PCを入れかえるときは、もう一度この画面で設定します
- 同期用のログインのパスワードは長くし、使い回さない
- どちらかのPCを入れかえる・同期をやり直すとき：両方で「同期をやめる」→ グループホームから設定し直す
