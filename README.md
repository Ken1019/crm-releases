# グループホーム業務管理システム（GHMS）

障害福祉サービス（共同生活援助）向けの業務一括管理システムです。
Windows PC 1台にインストールし、ブラウザで操作します。事業所内LANの他のPC・タブレットからも利用できます。

## 主な機能

| 分類 | 機能 |
|---|---|
| ダッシュボード | 受給者証・障害支援区分の期限、個別支援計画の期間終了・モニタリング予定、計画未作成者、本日の日誌の記入状況、委員会（虐待防止・身体拘束適正化・感染症・BCP）の最終実施日 |
| 入居者 | 入居者台帳（受給者証・支給決定期間・緊急連絡先・服薬・主治医など）、個別支援計画・モニタリング |
| 日誌・記録 | **1日分まとめて入力できる日誌画面**（業務日誌＋入居者ごとの支援記録：体温・食事・服薬・様子・記録）、ヒヤリハット・事故報告、会議・委員会記録 |
| 職員・キャリアパス | 職員台帳、キャリアパス等級（職位・職責・任用要件・賃金体系・昇給基準）、研修計画（年間）、研修受講記録、人事評価・面談、職員別の勤続年数・研修時間一覧 |
| 加算 | 加算マスタ（単位数・届出日・要件・必要書類）、利用者別加算、**月ごとの要件チェック**と概算単位数・金額 |
| 処遇改善 | 年度計画（区分・加算率・報酬総額見込）→加算額見込の自動計算、職員別配分（月額・賞与）、差額・月額改善割合の確認、区分に応じた要件チェック（キャリアパス要件Ⅰ〜Ⅴ・月額賃金改善・職場環境等） |
| 入院・帰宅・外泊 | 入院・帰宅（帰省）・外泊の登録（行き先・担当者・理由・持ち物）、**期間を月の実績に自動反映**、入院中は入居者の状態を自動で「入院中」に、ホームと日誌に不在の方を表示、**連絡のやりとりを時系列で記録**（相手・方法・内容・今後の対応）、入院中に7日以上連絡がないとお知らせ、今月の面会回数 |
| 連絡記録 | 家族・病院・相談支援専門員・日中活動先などとの連絡を記録。入居者の詳細画面に最近の支援記録・連絡・入院状況をまとめて表示 |
| 請求・お金 | **月ごとの実績入力**（在居・日中支援・外泊・帰宅・入院を表で入力）、**給付費の概算**（基本報酬＋加算＋処遇改善、利用者負担の上限額を反映）とサービス提供実績記録のExcel、**利用料の請求書・領収書**（家賃・家賃助成・食費・光熱水費・日用品費・利用者負担、月途中の入退居は日割り）、入金管理と未入金のお知らせ、**預り金**の出納帳・残高 |
| 勤務表 | 職員×日付の勤務表、月の勤務時間・**常勤換算**（職種別）、夜間の勤務者がいない日の表示、勤務形態一覧表のExcel |
| 書類の管理 | 契約書・重要事項説明書・同意書などの登録、入居者ごとに**そろっているか一覧**、更新日のお知らせ |
| 資料作成 | 全一覧のExcel出力、月次の業務日誌・支援記録、入居者別の支援記録、キャリアパス表、処遇改善配分表、詳細画面の印刷（PDF保存） |
| 管理 | ログイン（管理者／職員の権限分け。職員権限では給与・人事情報は非表示）、操作履歴、バックアップ |

> **注意**：加算の単位数・処遇改善加算の加算率・算定要件は報酬改定ごとに変わります。
> 初期データは項目名と要件の概要のみで、単位数は空欄です。必ず最新の報酬告示・留意事項通知・指定権者（自治体）の案内で確認して入力してください。
> 加算・給付費・利用者負担額の金額は概算です。国保連への請求は請求ソフト（電子請求受付システム等）で行い、その結果を正としてください。
> 基本報酬の単位数（「請求・お金」→「基本報酬の単位数を設定する」）も最新の報酬告示で確認して入力してください。

## インストール（Windows）

1. [リリースのページ](https://github.com/Ken1019/crm-releases/releases/latest) から `GHMS-Setup-版.exe` をダウンロード
2. ダブルクリックして画面の案内どおりに進める（Pythonなどは不要です）
   - 「Windowsによって PC が保護されました」と出たら「詳細情報」→「実行」を押す（電子署名がないため表示されます）
   - サーバーにするPCでは「Windowsの起動時にGHMSを自動で起動する」にチェック
   - 他のPC・タブレットからも使うときは「事業所内の他のPC・タブレットからも使う」にチェック
3. 完了するとブラウザが開くので、事業所名と管理者アカウントを登録して開始

| 場所 | 内容 |
|---|---|
| `C:\Program Files\GHMS` | プログラム（更新で入れ替わる） |
| `C:\ProgramData\GHMS\data` | **データ**（入居者・日誌など。更新・アンインストールしても消えない） |
| `C:\ProgramData\GHMS\config.ini` | 設定（`[server]` の `lan = 1` で他のPCから接続可、`port = 8000`） |
| `C:\ProgramData\GHMS\logs` | 動作の記録（困ったときの調査用） |

スタートメニューの「GHMS を開く」「GHMS を停止する」「データのフォルダを開く」から操作できます。
他のPC・タブレットからは `http://（サーバーPCのIPアドレス）:8000/` を開きます。

### 更新（ネット経由）
- 新しい版が公開されると、管理者のホーム画面に「新しい版があります」と表示されます（1日1回自動で確認）
- 「設定」→「ソフトを最新の版に更新する」で内容を確認し、**サーバーのPCで**「今すぐ更新する」を押す
- 自動で、ダウンロード → 改ざん・破損の確認（SHA-256）→ データのバックアップ → 入れ替え → 再起動 まで行います
- 確認で送るのは版の番号だけで、入居者などのデータが外に送られることはありません

### 新しい版を出すとき（開発者向け）
1. `ghms/__init__.py` の `VERSION` を上げ、`CHANGELOG.md` の先頭に「## 版の番号」と変更内容を書く
2. コミットして `v版の番号`（例 `v1.0.1`）のタグを push する
3. GitHub Actions が Windows でテスト → `GHMS.exe` とインストーラーを作成 → インストールの動作確認 → リリースとして公開（`GHMS-Setup-版.exe` と更新情報 `latest.json`）
4. 各事業所のGHMSに「新しい版があります」と表示される

タグを付けずに push したときは、公開せずに Windows でのビルドと動作確認だけを行います（成果物は Actions の画面からダウンロード可）。

### Pythonで動かす場合（開発・お試し）
1. [Python 3.11 以降](https://www.python.org/downloads/windows/) をインストール（「Add python.exe to PATH」にチェック）
2. このフォルダで `start.bat` をダブルクリック（他のPCからも使うときは `start_lan.bat`）

## ログインと個人情報の保護
入居者の情報は大切な個人情報（要配慮個人情報を含む）のため、次の仕組みを入れています。

| 仕組み | 内容 |
|---|---|
| 一人ひとりのアカウント | 管理者が「設定 → ログインする人を追加する」で職員ごとに作成。使い回しはしない |
| 権限 | **管理者**：すべて／**職員**：日誌・入居者・入院帰省・実績・預り金など日々の業務のみ（職員情報・給与・処遇改善・請求書・設定は見られない） |
| 初回のパスワード変更 | 管理者が作成・再設定した仮のパスワードは、本人が最初のログインで必ず変更 |
| パスワードの決まり | 8文字以上・英字と数字の両方・ユーザー名と同じは不可（保存は復元できない形＝ハッシュ） |
| ロック | 5回続けて間違えると15分ロック（管理者が解除可） |
| 自動ログアウト | 操作がないと30分（PINのときは15分・設定で変更可）でログアウト。ログアウト後は「戻る」でも内容が出ない |
| 停止 | 退職者などは「停止」にすると、記録を残したままログイン不可に |
| PINで交代ログイン | 管理者が登録した事業所の端末だけ、名前を押して**4桁のPIN**でログインできる（交代は「👥 交代する」）。登録していない端末ではPIN不可。推測されやすいPIN（1111・1234・1212など）は不可、5回間違えるとロック、PINで入ったときは15分で自動ログアウト。**PINで入った管理者は、管理者の画面を開く前にパスワードで本人確認** |
| 操作の記録 | ログイン・ログイン失敗・入居者情報などの閲覧・登録・変更・削除・Excel出力を、誰がいつ行ったか記録（画面からは消せない） |
| 持ち出しの制限 | 職員のExcel出力・バックアップは、管理者が設定で許可したときだけ |

あわせて、次の運用をおすすめします。
- サーバーにするPCは Windows の **BitLocker**（ドライブの暗号化）を有効にし、Windows のログインにもパスワードを設定する
- バックアップを保存するUSBメモリ・外付けドライブも暗号化し、鍵のかかる場所に保管する
- 事業所内のネットワーク（Wi-Fi）はパスワード付きにし、インターネットには公開しない

## データとバックアップ
- データはすべて `ghms.sqlite3` に保存されます（インストール版は `C:\ProgramData\GHMS\data`、Python版は `data` フォルダ。`secret_key` も一緒に保管）
- ネット経由の更新の前には、自動で `data\backup` にバックアップを作ります
- インストール版：`"C:\Program Files\GHMS\GHMS.exe" --backup D:\GHMSバックアップ` で日付付きのコピーを作ります（動かしたままでOK）
- Python版：`backup.bat` で `backup\` フォルダに日付付きでコピーします。引数で保存先を指定可（例：`backup.bat D:\GHMSバックアップ`）
- Windows のタスクスケジューラで毎日実行し、外付けドライブ等にも保管することを推奨します
- 画面の「管理 → バックアップをダウンロード」でも取得できます

## 項目の追加・カスタマイズ
`ghms/entities.py` に項目を1行追加すると、DB・入力画面・一覧・Excel出力に自動で反映されます（既存データはそのまま残ります）。

## 開発者向け
```
pip install -r requirements.txt pytest
python -m pytest
python run.py            # http://127.0.0.1:8000
```
構成：Python / Flask / SQLite / openpyxl / waitress（外部CDN不使用・オフライン動作）
