🔄 本部とグループホームの同期

{% if not cfg %}

本部のPCとグループホームのPCで、同じデータを使えるようにします。データは暗号化してから Firebase（給与計算ソフトで使っている受け渡し場所）に置くので、Google や Firebase からは中身が見えません。
ふだんは、グループホームで日々の入力（日誌・記録・実績・勤務の確定など）、本部で請求・給与・経費・加算・設定・ログインする人の追加を行います。本部で入力を直すときは「本部操作」をオンにします（その間、グループホームのPCは見るだけになります）。

  1. 本部のPCにGHMSを入れ、はじめての設定・入居者や職員・グループホームの職員のログインを入れておきます。
  2. 本部のPCで、下の「① このPCで始める」をします。終わったら「接続ファイルを保存」して、USBメモリに入れます。
  3. グループホームのPCにGHMSを入れ、はじめての設定をすませてから（ここで作ったログインは、あとで本部のログインに置きかわります）、この画面の「② 接続ファイルで参加する」でファイルを選びます。本部のデータがすべて届きます。
  4. Firebase の準備（同期用のログイン・データベースのルール）は「docs/同期の設定.md」を見てください。
